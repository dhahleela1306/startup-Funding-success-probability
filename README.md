Startup Funding Success Probability Analysis
Project Overview

This project analyzes the factors that influence startup funding success using Python and data analysis techniques. The objective is to identify the characteristics that increase the probability of a startup receiving funding.

Objectives
Analyze startup funding data.
Identify the factors affecting funding success.
Perform statistical analysis.
Visualize trends using charts.
Generate business insights from the dataset.
